# Alyn Rose F. Valencia — Personal Portfolio

A responsive personal portfolio website developed for the CIT 240 portfolio assignment using HTML5, CSS3, and Vanilla JavaScript. This portfolio showcases my background, technical skills, projects, and capstone project as an Information Technology student.

- Semantic HTML5 structure
- Responsive layout using CSS Grid and Flexbox

- Smooth section scrolling
- About Me section
- Technical Skills section
- Featured Projects section
- Capstone Project Showcase
- Contact section
- GitHub and LinkedIn profile links
